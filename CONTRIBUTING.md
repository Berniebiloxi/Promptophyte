# Contributing to Promptophyte

Thanks for being here. This project is meant for people with no technical
background, so the most valuable contributions are often the simplest ones:
telling us where it lost you.

## Ways to help

- **Open an issue** if something in the handbook is confusing, out of date,
  or just plain wrong — or if the meta-prompt asked you a question that made
  no sense, or missed something it should have asked. "I got stuck here and
  didn't know what to do" is a genuinely useful issue. You don't need to
  suggest a fix.
- **Open a pull request** if you want to fix a typo, clarify a passage, or
  add an explanation for a term that tripped you up. Small, focused changes
  are easiest to review and merge.
- **Share how it went.** If you built something with this, we'd love to
  hear what worked and what didn't. That feedback shapes the next version.

## A few ground rules

- Keep the plain-language tone. If a change adds jargon without explaining
  it, it's probably going the wrong direction.
- One change per pull request where you can — it keeps things moving.
- Be kind in issues and reviews. Everyone here is learning something.

## About the core files

`meta-prompt.md`, `quickstart.md`, `handbook/level-1.md`, and
`handbook/level-2.md` are the heart of the project. Changes to them are
very welcome, but they get a closer read than other files — explain *why*
in your pull request so the reasoning is on the record.

That's it. Opening a pull request will hand you a short template to fill
out — it's just a prompt, not a checklist to sign.
