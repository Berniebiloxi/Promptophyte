What this is

A prompt, not a program. Paste it into an AI coding agent and it interviews you first, in plain language, before writing any code. Every answer becomes part of a written plan the AI actually follows.

You never write code. Your job is deciding what gets built and why — directing a contractor, not being one.

Works with any AI agent

Built and tested against Claude Code. Works as plain text with ChatGPT, Codex, Cursor, Gemini CLI, and most other AI coding tools — nothing to install to try it.

Where this fits

This isn't competing with developer-focused tools like GitHub Spec Kit, BMAD, or GSD — those are excellent once you already code. Promptophyte exists for the stage before that: the on-ramp for someone who's never directed an AI to build anything, written for a reader who knows how to browse the web and not much else yet.
